- **Reason**: `mmapAlloc` requires the `emscripten_builtin_memalign` native symbol, which is not exported by the compiled WASM module used in the test harness.
- **Impact**: mmap-related code paths in tomefs are untested in this environment. These tests likely pass in a full Emscripten build with mmap support enabled.
- **Action**: No fix needed unless mmap support is a priority. If it is, the harness WASM module (`emscripten_fs.wasm`) would need to be rebuilt with `-s ALLOW_MEMORY_GROWTH=1` and the `memalign` export enabled.
